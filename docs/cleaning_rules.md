## Method

Each rule was decided with these steps:

```
1. PROBE      What does the test flag? (counts: cells and company-lines)
2. CAUSES     List the possible explanations (no business, losses booked elsewhere, data error)
3. EVIDENCE   Run follow-up checks that tell the causes apart (notebook §x.2, §x.3)
4. IMPACT     Which methods does it break? (paid CL, reported CL, expected claims, BF)
5. LEAKAGE    Decided using known cells only? If yes, it's a quality rule
6. ACTION     Breaks every method → drop | breaks some → exclude from those | breaks none → note
7. RECORD     Rule, reason, drop condition, type, flags, evidence
```
